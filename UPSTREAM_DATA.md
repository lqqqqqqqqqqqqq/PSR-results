# Upstream data and implementation

The benchmark datasets are third-party research assets, not datasets created
by the PSR authors. Refer to the sources cited in the manuscript and to:

- LBMKGC code and acquisition instructions: https://github.com/guoynow/LBMKGC
- Official LBMKGC paper: https://papers.neurips.cc/paper_files/paper/2025/hash/a254abbfdd029d388fc35fd850bbc551-Abstract-Conference.html

This result-only package intentionally excludes raw benchmark splits and
feature tensors. The authors' private preservation package retains the exact
experiment inputs and hashes. Exact dataset-version notes must accompany the
model-reproduction release; this package does not silently clean, swap or
reconstruct dataset splits.

Do not infer redistribution rights merely from upstream download availability.
